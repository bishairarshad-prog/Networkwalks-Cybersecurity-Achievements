# Networkwalks - My Cybersecurity Journey

Hi, I am Bishair. This repository is about my Cybersecurity learning journey at Networkwalks. I created this repository to document all my completed CTF challenges, captured flags, and the skills I learned during my practice.

I am learning Cybersecurity practically by solving real challenges instead of only reading theory.

## Challenges Completed

### 1. Password Cracking - Flag 1
In this challenge, I learned how weak passwords can be cracked. I practiced different password cracking techniques and understood why strong passwords are important for security.

### 2. Password Cracking - Flag 2
This was the second level of Password Cracking. In this challenge, I learned more advanced techniques and how attackers use different tools and wordlists to break passwords. After completing this, my understanding of password security became much stronger.

### 3. Persistence - Flag 1
In this challenge, I learned about Persistence. Persistence means how an attacker maintains access to a system even after the system is restarted. I learned how persistence works and why it is important to detect and prevent it.

## Skills I Learned

- Password Cracking and how to protect against it
- Persistence Techniques and how attackers maintain access
- Linux Fundamentals and basic commands
- Cybersecurity Fundamentals and real-world attack methods
- Problem Solving through CTF challenges
